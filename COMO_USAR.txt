========================================================================
       BARBEARIA MICHAEL BARBER - SISTEMA DE GESTÃO & CAIXA PORTÁTIL
========================================================================

Este sistema foi projetado para funcionar 100% OFFLINE (sem internet),
diretamente no notebook ou em um PEN DRIVE portátil, sem mensalidades
ou assinaturas recorrentes.

------------------------------------------------------------------------
USO DIRETO NO PEN DRIVE (PORTÁTIL / PLUG-AND-PLAY):
------------------------------------------------------------------------
1. Copie a pasta inteira do sistema para o seu Pen Drive.
2. Conecte o Pen Drive em qualquer computador ou notebook com Windows.
3. Dê 2 cliques no arquivo: "iniciar_sistema.bat"
4. O sistema abrirá automaticamente a tela do Caixa no navegador.

* Graças ao executável em "bin/node.exe", o sistema funciona em qualquer
  computador com Windows, mesmo que nunca tenha instalado o Node.js antes!

------------------------------------------------------------------------
ONDE FICAM OS DADOS:
------------------------------------------------------------------------
- Todos os atendimentos, barbeiros e serviços ficam salvos no arquivo:
  backend/barbearia.db
- Quando você usa o sistema pelo Pen Drive, todas as vendas são salvas
  automaticamente dentro do próprio Pen Drive.

------------------------------------------------------------------------
BACKUP (CÓPIA DE SEGURANÇA):
------------------------------------------------------------------------
- Para fazer um backup, basta copiar a pasta inteira ou o arquivo
  "backend/barbearia.db" para onde desejar (ex: seu e-mail, HD externo).

------------------------------------------------------------------------
PROTEÇÃO DA ABA RELATÓRIOS (ÁREA DO DONO):
------------------------------------------------------------------------
- A aba "Relatórios" é protegida por senha do Dono. Os barbeiros usam o
  sistema normalmente (atendimentos, histórico, cadastros), mas só quem
  tem a senha do Dono consegue ver os relatórios financeiros.
- PRIMEIRO USO: ao clicar em "Relatórios", o sistema pede para definir
  a senha do Dono (mínimo 4 caracteres). Defina e confirme.
- Depois disso, toda vez que abrir "Relatórios" será pedida essa senha.
- ESQUECEU A SENHA? Pode resetar apagando tudo, ou com o Dono definindo
  novamente em outro navegador via o terminal/console - procure o Carlos.
